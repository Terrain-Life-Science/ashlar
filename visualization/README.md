# Ashlar Registration Visualizer

React + Vite web application for visualizing registration pipeline results.

## Setup

```bash
cd visualization
npm install
```

## Development

```bash
npm run dev
```

The app will open at http://localhost:3000

## Build

```bash
npm run build
```

## Usage

1. Place `report.json` in the `public` directory (or serve via API)
2. Start the dev server: `npm run dev`
3. View the visualization in your browser
